entirely from OpenAlex. **Topic count falls as the corpus grows** (15 → 5) because
`min_cluster_size = max(6, N/40)` scales with N, so a 4403-paper corpus demands
110-paper clusters. This is a parameter artefact, not a property of the literature,
and is worth stating in Sec. VII.

The interface's 1000 cap is **UI-only** (`ui/src/routes/input.tsx:13`); the engine
accepts any integer (`engine/api.py:37`), so `POST /analyze {"papers": 5000}` bypasses it.

## Prominence formula and verdict rule (LaTeX)

Verified against `engine/engine/gaps.py:20-60` and `engine/engine/agent.py:25-106`.

```latex
Let $T=\{t_1,\dots,t_K\}$ be the non-outlier topics, $n_k=|t_k|$, and let
$\mathbf{c}_k$ be the mean of the $L_2$-normalised Sentence-BERT embeddings
$\mathbf{e}_p$ of the papers in $t_k$. A paper \emph{bridges} $(t_i,t_j)$ when it
is similar to both centroids above a fixed threshold $\tau=0.45$:
\begin{equation}
b_{ij}=\bigl|\{\,p:\ \mathbf{e}_p^{\top}\mathbf{c}_i>\tau\ \wedge\ \mathbf{e}_p^{\top}\mathbf{c}_j>\tau\,\}\bigr|
\end{equation}
The count ranges over the whole corpus, so a bridging paper need not belong to
either topic. For each unordered pair,
\begin{align}
s_{ij}&=\frac{1}{1+b_{ij}}\\[2pt]
m_{ij}&=\sqrt{n_i\,n_j}\\[2pt]
r_{ij}&=1+\tfrac{1}{2}\max\!\left(0,\;1-\frac{Y-\min(\bar{y}_i,\bar{y}_j)}{\Delta}\right),\qquad\Delta=10
\end{align}
where $\bar{y}_k$ is the mean publication year of $t_k$ and $Y=\max_p y_p$. The
prominence score is their product:
\begin{equation}
P_{ij}=s_{ij}\cdot m_{ij}\cdot r_{ij}
\end{equation}
$P_{ij}$ is deliberately unnormalised ($s_{ij}\in(0,1]$, $r_{ij}\in[1,1.5]$,
$m_{ij}$ unbounded), so it ranks candidates within a run and is not comparable
across runs. Pairs with $b_{ij}\le 3$ are preferred; if none qualifies the full
ranked list is used, so the stage never returns empty. The top $G=8$ proceed.
```

```latex
For each candidate the agent generates $q=2$ search queries with a language model
(Claude Haiku 4.5, temperature $0$), each pairing one phrase from $t_i$ with one
from $t_j$. Each query is issued to OpenAlex as a \emph{count-only} request
restricted to the last three years; no documents are returned to the model. With
$h_{ij}$ the maximum count over the queries,
\begin{equation}
v_{ij}=\begin{cases}
\textsc{unverified}, & \text{every query failed}\\
\textsc{rejected},   & h_{ij}\ge 25\\
\textsc{weak},       & 8\le h_{ij}<25\\
\textsc{confirmed},  & h_{ij}<8
\end{cases}
\end{equation}
with confidence $c_{ij}=\max(0,\,1-h_{ij}/25)$ in the latter two cases and
$c_{ij}=0$ otherwise. A candidate is retained iff $v_{ij}=\textsc{confirmed}$; no
separate confidence threshold is applied.
```

> The language model's role is confined to **query formulation**. It does not read
> retrieved papers and does not issue the verdict. Sec. III-F, Table I's
> "Validation mechanism" row, and the claims about cited identifiers, rationales
> and $\theta=0.6$ must all be amended.
